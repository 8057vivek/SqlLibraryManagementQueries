# Library Management System SQL Project 📚

This project offers a hands-on, beginner-friendly approach to learning SQL fundamentals and database design by creating a simple **Library Management System**. It's an excellent resource for anyone looking to practice their SQL skills with a practical, real-world scenario.

---

## Project Overview

The project is built around a **relational database model** to manage a small library's data. It includes the following key tables to handle essential library operations:

- **Books**: Stores information about all the books in the library.  
- **Authors**: Contains details about the authors of the books.  
- **Members**: Manages information for all library members.  
- **BorrowingRecords**: Tracks which books are borrowed, by whom, and for how long.  

---

## Key Features

- **Database Schema Design**: Learn how to structure a database with multiple related tables.  
- **Data Management**: Practice basic SQL queries to insert, update, and delete data within the tables.  
- **Data Retrieval**: Write queries to retrieve and analyze information, such as finding books by a specific author or listing all borrowed books.  
- **Relational Integrity**: Use foreign keys to establish relationships between tables and ensure data consistency.  

---

## Getting Started

To get started with this project, you'll need a relational database management system (RDBMS) like **MySQL**. The repository includes `.csv` files for each table, which you can import to populate the database with sample data.

### Steps:

1. **Set up your database.**  
2. **Create the four tables**: `Books`, `Authors`, `Members`, and `BorrowingRecords`. Define the appropriate primary and foreign keys to link them together.  
3. **Import the data** from the provided `.csv` files into your tables.  
4. **Open the** `Library Management System Queries using MYSQL.pdf` file to view the pre-written SQL queries and practice running them against your database.  

---

This project is a great way to solidify your understanding of SQL and database principles. Feel free to modify the queries, add new ones, or expand the database schema to challenge yourself further.
